# Sales Collection Hub - AHQAM

A production-oriented, Arabic-first, bilingual dynamic mobile application and responsive Admin Web Dashboard for managing recurring sales data collection requests.

## Architecture

The system consists of three main parts:
1. **Admin Dashboard (`/src`)**: Built with React, Vite, and TypeScript. Used by administrators and supervisors to create dynamic forms, import target data, assign records, and monitor progress.
2. **Mobile Application (`/mobile`)**: Built with Flutter (Riverpod, Freezed, GoRouter). Used by sales representatives to view their assigned records, fill dynamic forms offline, and sync when online.
3. **Backend Services (`/firebase/functions`)**: Built with Firebase Cloud Functions (Node.js 20). Handles authentication, custom claims, data import, notification dispatching, assignment management, and extension points.

## Security

Security is enforced at multiple layers:
- **Authentication**: Custom authentication with bcrypt hashing, enforcing complex passwords, device binding, and administrative locks.
- **Role-Based Access Control (RBAC)**: Custom claims define roles (Admin, Supervisor, Rep) and scope constraints (RegionNo, BranchNo).
- **Firestore Rules**: Granular, schema-validating rules ensure data integrity. Responses can only be created by assigned representatives, and requests are immutable once published.
- **Storage Rules**: Limit file uploads to 5MB, restrict MIME types to images/PDFs, and map paths to Request IDs.

## Data Schema & Versioning

- Forms are built dynamically. Upon publishing a request, a `schemaSnapshot` is saved permanently to ensure historical integrity (Phase 4). Subsequent modifications do not alter the snapshot of active requests.

## External Integrations

- **Extension Adapter**: See `firebase/functions/src/externalIntegrationAdapter.ts` for the foundational hook point designed to integrate with SAP, ERP, SQL Server, and Power BI. Active implementations can be injected there without altering core logic.

## Deployment

### Prerequisites
- Node.js 20
- Flutter SDK (latest stable)
- Firebase CLI (`npm install -g firebase-tools`)

### Firebase Backend
```bash
cd firebase/functions
npm install
npm run build
firebase deploy --only functions,firestore:rules,storage
```

### React Admin Dashboard
```bash
npm install
npm run build
firebase deploy --only hosting
```

### Flutter Mobile App
```bash
cd mobile
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter build apk --release
```

## Maintenance & Monitoring
- **Health Checks**: Endpoint provided via `monitoring.ts` (`getSystemHealth`).
- **Audit Logging**: Write operations across critical collections automatically trigger audit trails (if implemented via triggers or admin dashboard interceptors).
